# Stockify
Inventory Management System - Mini Project 3.

## Teknologi
PHP, MySQL, PDO, XAMPP, VS Code, phpMyAdmin.

## Menjalankan
1. Start Apache dan MySQL di XAMPP.
2. Letakkan folder `stockify` di `C:\xampp\htdocs\`.
3. Buka phpMyAdmin dan import `database/schema.sql`.
4. Buka `http://localhost/stockify/public/login.php`.

## Akun demo
Admin: `admin` / `password`
Staff: `staff` / `password`

Fitur dasar: login/role, dashboard, kategori, produk, supplier, many-to-many schema produk-supplier, transaksi masuk/keluar, riwayat, laporan, search nama/SKU, filter, sorting, validasi stok, prepared statements, dan escaping output.
